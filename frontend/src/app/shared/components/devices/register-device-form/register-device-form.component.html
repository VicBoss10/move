1) Conectar sensor a la fuente de energía

Conecta el sensor a una fuente de alimentación estable (5V/2A recomendados). Tras conectar, el LED rojo del dispositivo debe encenderse de forma fija.

Si el LED no enciende, prueba lo siguiente:

  • Verifica que el cable USB esté en buen estado y correctamente conectado.
  • Usa otra fuente de alimentación (otro adaptador o puerto USB).
  • Prueba con otro cable compatible (datos/charging).
  • Si persiste, reinicia el sensor desconectando y volviendo a conectar la alimentación.

Una vez el sensor esté alimentado y con el LED encendido, continúa con el paso de provisioning mediante el portal cautivo del dispositivo (ver pasos posteriores).

2) Portal cautivo y LED indicador

Cuando el portal cautivo esté activo, el LED azul del dispositivo parpadeará — eso indica que la red cautiva está lista para conectarse desde tu teléfono u ordenador.

Conectar al portal:

  1. En tu teléfono busca la red Wi‑Fi del sensor (ej. MOVE-XXXX).
  2. Conéctate a la red; abre el navegador y serás redirigido al portal cautivo.
  3. Sigue las instrucciones del portal para configurar la red local y credenciales del sensor.

Si el LED azul no parpadea: espera hasta 30s, verifica la alimentación y reinicia el sensor. Si persiste, contacta soporte.

3) Validación de credenciales Wi‑Fi

Mientras el sensor valida las credenciales Wi‑Fi proporcionadas por el portal, ambos LEDs (rojo y azul) permanecerán encendidos de forma fija. Esto indica que el dispositivo está comprobando la conectividad con la red local.

Tiempo estimado: 10–30 segundos. Si la validación tarda más de 30s, revisa las credenciales o verifica la disponibilidad de la red Wi-Fi.

4) Seleccionar ubicación

Si la validación es correcta:

  • El sensor se conectará a la red y hará un registro provisional en la base de datos.
  • Se solicitará seleccionar la ubicación del sensor en la aplicación.
  • Finaliza el registro para iniciar la validación de datos.
  • No desconectes el dispositivo durante el proceso de validación (aprox. 3 minutos).

5) Registro exitoso

Si luego del proceso de validación todo funcionó correctamente, el dispositivo cambiará su estado a "Activo" y el proceso de registro quedará finalizado.

Indicador LED: la luz azul parpadeará cada 30 segundos para indicar que el sensor está enviando datos periódicamente al servidor.

Verifica en la aplicación que el dispositivo aparece como activo y comprueba las lecturas iniciales en la pantalla de indicadores.
