Arquitectura del Sistema

Visión general de los componentes, comunicación entre servicios y recomendaciones para despliegue y escalado.

Componentes principales
  • Frontend (Angular): Interfaz de usuario, dashboards, formularios de configuración.
  • Backend (Spring Boot): API REST, seguridad (Keycloak), lógica de negocio y persistencia.
  • Detector (Python): Servicio de detección que procesa streams y emite eventos.
  • Base de datos: Almacenamiento de eventos, dispositivos, ubicaciones y usuarios.
Comunicación

Los detectores pueden enviar eventos directamente al backend mediante HTTP o usar un broker (opcional) para desacoplar procesamiento y recibir picos de carga. El frontend consulta la API REST protegida por tokens JWT gestionados por Keycloak.

Despliegue y escalabilidad

Para cargas mayores, escale horizontalmente los detectores y el backend. Use contenedores (Docker) y orquestadores (docker-compose/ Kubernetes) y reserve recursos para procesamiento de video. Considere almacenamiento en caché para consultas intensivas y particionado de datos por ubicación/fecha.

Seguridad y operación

Proteja endpoints administrativos con roles Keycloak, audite accesos y mantenga certificados TLS en los puntos de exposición. Monitorice latencia, tasa de eventos y errores en los detectores para detectar degradación temprana.
