Arquitectura del Sistema

Componentes, comunicación y recomendaciones de despliegue

Componentes Principales

  • •

    Frontend (Angular)

    Interfaz de usuario, dashboards y formularios

  • •

    Backend (Spring Boot)

    API REST, seguridad y lógica de negocio

  • •

    Detector (Python)

    Procesamiento de streams y generación de eventos

  • •

    Base de Datos

    Eventos, dispositivos, ubicaciones y usuarios

Comunicación

Los detectores envían eventos al backend mediante HTTP o un broker (opcional) para desacoplar procesamiento.

✓ Protección de API con JWT y Keycloak

Despliegue & Escalabilidad

  • → Escale horizontalmente detectores y backend
  • → Use Docker y Kubernetes/docker-compose
  • → Almacenamiento en caché para consultas intensivas
  • → Particionado de datos por ubicación/fecha

Seguridad & Operación

  • 🔒 Proteja endpoints con roles Keycloak
  • 🔒 Audite accesos y mantenga certificados TLS
  • 🔒 Monitorice latencia y tasa de eventos
