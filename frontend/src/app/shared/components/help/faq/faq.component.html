Preguntas frecuentes

Haz click en cualquier pregunta para desplegar la respuesta. Las preguntas están agrupadas por secciones.

Dispositivos

¿Qué tipos de dispositivos puedo registrar?
Puedes registrar cámaras (streams RTSP/HTTP/MJPEG) y sensores ambientales (CO₂, PM2.5/PM10, temperatura, humedad). Asigna cada dispositivo a una `Ubicación` para facilitar análisis y filtrado.
¿Qué configuración recomiendan para cámaras?
Para detección, use resolución ≥720p y 15–20 FPS. RTSP ofrece mejor latencia para modelos en tiempo real. Ajusta bitrate y FPS según la capacidad de la red y CPU del detector.

Streams y seguridad

¿Cómo configuro un stream seguro?
No expongas credenciales en URLs públicas. Si usas credenciales en la URL (p. ej. RTSP), asegúrate de que la red sea privada o usa VPN/túneles. Cambia contraseñas por defecto y usa HTTPS/TLS donde sea posible.
¿Qué protocolos son compatibles?
Soportamos RTSP, HTTP(S) y MJPEG para cámaras. Para sensores, usamos HTTP/HTTPS o integraciones específicas del dispositivo.

Umbrales y alertas

¿Cómo funcionan los umbrales de alerta?
Define niveles (info/warning/critical) por métrica. El sistema compara lecturas y conteos contra esos límites y genera alertas que puedes revisar en la sección de notificaciones o exportar para auditoría.

Operación y troubleshooting

Mi dispositivo no envía datos, ¿qué reviso?
  • Verifica conectividad de red entre dispositivo y backend.
  • Revisa credenciales y rutas de stream (RTSP/HTTP).
  • Consulta logs del dispositivo y del backend (endpoint de ingestión).
  • Comprueba el estado en la tabla de dispositivos del panel.

Administración

¿Quién puede gestionar usuarios y configuraciones?
Operaciones sensibles están protegidas por roles en Keycloak. Solo usuarios con rol admin pueden acceder a la gestión de usuarios y parámetros del sistema.
