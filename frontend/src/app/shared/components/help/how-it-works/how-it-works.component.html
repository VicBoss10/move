Cómo Funciona

Flujo de datos y componentes del sistema

1. Flujo de Datos

Los dispositivos (cámaras y sensores) envían datos al sistema:

Cámaras

RTSP/HTTP para video en tiempo real

Sensores

Lecturas periódicas de CO₂, temperatura, etc.

2. Detección de Vehículos (ML)

El microservicio Python procesa streams en tiempo real:

  • → Extrae frames de video
  • → Ejecuta modelos ML (YOLO11n)
  • → Emite eventos con clase, bounding box y score

3. Backend & Seguridad

Spring Boot procesa y almacena datos:

✓ API REST protegida por Keycloak

Enriquece eventos con metadatos (ubicación, timestamp, confianza) y aplica reglas de umbral/alerta

4. Visualización & Análisis

Angular consume la API para mostrar dashboards interactivos:

Series temporales
Análisis por ubicación
Mapas de calor

Consejos Prácticos

  • → Prefiera RTSP para baja latencia en detección en tiempo real
  • → Use resolución ≥720p y 15–20 FPS para la mayoría de modelos
  • → Configure umbrales de alerta en la UI
  • → Asigne dispositivos a ubicaciones para contextualizar eventos y mejorar análisis
