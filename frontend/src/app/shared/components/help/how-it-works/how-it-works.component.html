Cómo Funciona

Resumen del flujo de datos, componentes involucrados y recomendaciones prácticas para operar el sistema.

Flujo de datos

Los dispositivos (cámaras y sensores) envían datos al sistema. Las cámaras transmiten video por RTSP/HTTP; los sensores envían lecturas periódicas. Un servicio de detección procesa los streams y genera eventos que el backend almacena y enriquece con metadatos (ubicación, timestamp, confianza).

Detección de vehículos

El microservicio de detección (Python) extrae frames, ejecuta modelos ML y emite eventos que contienen clase, bounding box y score. El backend conserva eventos y dispara reglas de umbral/alerta según las políticas configuradas.

Backend y seguridad

Spring Boot expone la API REST protegida por Keycloak. Solo roles autorizados pueden gestionar usuarios, dispositivos y configuraciones. Recomendamos revisar `SecurityConfig` para adaptar rutas protegidas y auditar roles en producción.

Visualización y análisis

El frontend Angular consume la API para mostrar datos en dashboards: series temporales, matrices de correlación y análisis por ubicación. Asigna dispositivos a ubicaciones para agrupar y filtrar correctamente los datos.

Consejos rápidos
  • Prefiera RTSP para baja latencia en detección en tiempo real.
  • Resolución ≥ 720p y 15–20 FPS suele ser suficiente para la mayoría de modelos.
  • Configure umbrales de alerta en la UI para recibir notificaciones tempranas.
  • Use ubicaciones para contextualizar eventos y mejorar los análisis.
