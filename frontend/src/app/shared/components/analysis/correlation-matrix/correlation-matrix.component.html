Cómo interpretar

  • ▲ Un valor cercano a +1 indica que ambas variables suben y bajan juntas (ej. más vehículos → más CO₂).
  • ▼ Un valor cercano a −1 indica relación inversa (ej. más humedad → menos PM2.5).
  • ◆ Valores entre −0.3 y +0.3 sugieren relación débil o nula entre las variables.
  • ⚠ Correlación no implica causalidad. Variables externas (meteorología, hora, etc.) pueden actuar como confundidores.
