Metodología: Los datos horarios de sensores y vehículos se agregan por slot de 1 h. Para cada desplazamiento k (−12 h … +12 h) se calcula el coeficiente de Pearson entre el vector de vehículos y el vector de contaminante desplazado k posiciones. Un k negativo indica que el tráfico _precede_ el cambio en el contaminante. La correlación no implica causalidad; factores meteorológicos pueden actuar como confundidores.
