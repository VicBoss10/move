MOVE es un sistema de monitoreo ambiental portátil. Mide contaminantes del aire (CO₂, partículas en suspensión, etc.) y los relaciona con el tráfico vehicular en tiempo real. Su diseño adaptable permite obtener datos precisos en cualquier lugar, ayudando a crear ciudades más saludables.

Monitoreo Ambiental Inteligente

El sistema IoT portátil tiene como objetivo medir contaminantes atmosféricos producidos por el tráfico vehicular y relacionarlos con el tipo y la cantidad de vehículos.

Utilizando sensores de bajo costo, conectividad IoT y modelos de inteligencia artificial como YOLO, se busca proveer información precisa y en tiempo real para apoyar la toma de decisiones ambientales y de movilidad.

Adquisición de Datos

Medición de CO₂, NOx, PM y condiciones ambientales con alta resolución espacial y temporal.

Inteligencia Artificial

Reconocimiento de tipo de vehículo mediante modelos de visión por computadora.

Características

Explora las funcionalidades

Sistema IoT portátil
para monitoreo ambiental

Un dispositivo móvil de bajo costo que mide contaminantes atmosféricos, reconoce el tipo de vehículo con IA y envía datos en tiempo real para la toma de decisiones ambientales.

Monitoreo ambiental

Sensores de CO₂, NOx, partículas (PM2.5 y PM10), temperatura y humedad para un análisis completo de la calidad del aire.

Inteligencia artificial

Identificación en tiempo real del tipo y cantidad de vehículos utilizando modelos de visión por computadora.

Datos en tiempo real

Envío de datos a la nube mediante WiFi/IoT, asegurando disponibilidad inmediata de la información para análisis.

Geolocalización móvil

Registro de posición GPS junto con los datos de contaminación, permitiendo mapear zonas críticas de la ciudad.

Visualización de datos

Plataforma web que muestra gráficos, estadísticas y mapas de contaminación integrando datos ambientales y vehiculares.

Bajo costo

Dispositivo portátil y accesible que reduce costos en comparación con estaciones fijas de monitoreo ambiental tradicionales.

Flujo de Trabajo

Cómo Funciona
Paso 01

Recolección de Datos

Los sensores IoT y la cámara capturan en tiempo real variables ambientales junto con información del tráfico vehicular.

Paso 02

Transmisión a la API

Los datos recolectados son enviados a través de una API REST, garantizando una comunicación segura y en tiempo real entre el dispositivo y el servidor.

Paso 03

Almacenamiento en Base de Datos

La información se organiza y almacena en una base de datos relacional, lo que permite mantener un historial de las mediciones ambientales y vehiculares.

Paso 04

Visualización para el Usuario

La interfaz de usuario consulta los datos almacenados y los presenta en paneles interactivos con gráficos, estadísticas y mapas en tiempo real.
